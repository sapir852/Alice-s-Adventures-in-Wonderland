# Alice’s Adventures in Wonderland 

This project is a 3D game inspired by *Alice in Wonderland*, created using **Unity** and programmed in **C#**.  
The game includes two different worlds that the player can explore while controlling Alice.

🎥 **Demo Video:** https://youtu.be/REsv1M4kNgY

---

## 🎮 Game Overview
You play as **Alice**, who moves from the real world into the magical Wonderland.  
Each world has its own design, atmosphere, and unique visual style.

The character movement is controlled using the **keyboard**.

---

## 🌍 Worlds Included
### ⭐ 1. Real World
Alice begins her journey in a simple, realistic environment.  
This world introduces basic movement and navigation.

### ⭐ 2. Wonderland
A colorful and mysterious fantasy world inspired by the original story.  
Players can explore the environment and enjoy the magical visuals.

---
